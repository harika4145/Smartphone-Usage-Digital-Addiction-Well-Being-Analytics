 📱 Smartphone Usage Data Analysis & Power BI Dashboard

📌 Project Overview

This project analyzes smartphone usage data to understand users' smartphone habits, screen time, app usage, data consumption, and other usage patterns.

The project uses **Power BI** to transform raw smartphone usage data into interactive dashboards and visualizations. The dashboard helps identify important trends and patterns in smartphone usage.

 🎯 Objectives

* Analyze smartphone usage patterns.
* Understand daily screen time and app usage.
* Identify frequently used applications.
* Analyze data consumption and usage behavior.
* Compare smartphone usage across different user categories.
* Create interactive and easy-to-understand visualizations using Power BI.
* Generate useful insights from the dataset.

 🛠️ Technologies Used

* **Power BI** – Data cleaning, transformation, visualization, and dashboard creation
* **Microsoft Excel / CSV** – Dataset
* **SQL** – Data storage and querying (if applicable)

 📂 Dataset

The project uses a smartphone usage dataset containing information related to smartphone users and their usage behavior.

The dataset includes information such as:

* User details
* Screen time
* App usage
* Data usage
* Call duration
* Number of notifications
* Other smartphone usage-related attributes
